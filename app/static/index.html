Use each for what it's designed for

Lakebase (Postgres)

Operational data — current policies, active claims, user sessions. Your web apps and APIs query here. Sub-100ms latency, point lookups, CRUD operations.

Lakehouse (DBSQL)

Full data history — years of transactions, all events, raw logs. Your analysts and BI tools query here. Scans terabytes with Photon distributed compute.
